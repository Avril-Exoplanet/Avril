# Figure provenance

The overview figures `avril-discovery-architecture.png`,
`planetary-census-gap-ai.png`, and `avril-core-vetting.png` are project-authored
explanatory artwork supplied for this release. They summarize the declared
software architecture and are not observational measurements.

The files `planetary-census-gap-validation.{png,svg}` and
`tess-discovery-queue-atlas.{png,svg}` are rendered deterministically by
`scripts/render_research_figures.py` from the frozen public artifacts in
`Engine/target_selection/metadata.json` and
`Engine/target_selection/tess_discovery_queue_v02.csv`.

The compact SVG diagrams remain available as technical documentation assets.
Image and component licenses used by the native application are recorded in
the repository-level `THIRD_PARTY_NOTICES.md` and `VendorLicenses/` directory.
